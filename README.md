BlackJack Game (Console)

Моя реализация классической карточной игры "Блэкджек" на языке C#. 
Это мой учебный проект, созданный спустя 5 месяцев после начала изучения программирования.

## 🚀 Особенности
- Реализована логика игры против дилера.
- Система ставок и управления балансом игрока.
- Валидация пользовательского ввода (защита от "дурака").
- Использование принципов ООП (классы, интерфейсы, наследование).

## 🛠 Технологии
- Язык: C#
- Платформа: .NET 8.0 / Console Apps

## 📈 Чему я научился в этом проекте
1. Работа с коллекциями (`List<T>`).
2. Применение объектно-ориентированного подхода (разбиение логики по классам: Player, GameBoard, Cards, GameLogger, IsGameOver, MyRandom).
3. Обработка ошибок и исключений (обработка некорректного ввода через `TryParse`).
4. Работа с Git и GitHub.

## Как запустить
1. Склонируйте репозиторий: `git clone https://github.com/RadarSunRay/BlackJack.git`
2. Откройте решение `.sln` в Visual Studio.
3. Нажмите `F5` для запуска.
